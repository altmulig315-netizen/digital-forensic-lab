# Digital forensic lab

Digital forensic lab i et tidlige stadie, den er koblet til de profesjonelle standardene og veiledningene som beskriver god praksis.

## Innhold

- [01 Prosess og kilder](01_Prosess_og_kilder/forensisk-prosess-og-kilder.md): femfasemodellen (identifisering, preservering, analyse, dokumentasjon, presentasjon) og krav til forensisk rapport, med kilder fra ISO/IEC 27037/27041/27042, NIST SP 800-86, RFC 3227, ACPO, SWGDE og ENFSI. Finnes også som [HTML-versjon](01_Prosess_og_kilder/forensisk-prosess-og-kilder.html).
